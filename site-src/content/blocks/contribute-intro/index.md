The Apache Fineract® community [welcomes contributors](https://cwiki.apache.org/confluence/display/FINERACT/Contributor%27s+Zone) who want to support the Fineract® technology. Our community builds everything from [this website](https://github.com/apache/fineract-site), to the [Fineract® code](https://github.com/apache/fineract), to [documentation](https://github.com/apache/fineract/tree/develop/fineract-doc/src/docs/en/) and best practices information.

We especially welcome additions and corrections to the [documentation](https://cwiki.apache.org/confluence/display/FINERACT/), wiki, and website to improve the user experience. Bug reports and fixes and additions to the Apache Fineract® code are welcome. Helping users learn best practices also earns good karma in our community.

Security vulnerabilities necessitate special handling: these must be reported privately and immediately to the Apache Fineract® Security Team, via email, to security at fineract.apache.org. Review and follow the [Apache Security Team vulnerability reporting guidelines](https://www.apache.org/security/), especially with regard to [working in private](https://www.apache.org/security/committers.html#possible) prior to public disclosure.
