About

infoWhat is Fineract?

Apache Fineract® is a sophisticated core banking system that provides comprehensive financial technology solutions. It offers robust features for client data management, loan and savings portfolio management, integrated real-time accounting, and extensive reporting capabilities.

settingsKey Features

  • tune Flexible Product Configuration
    Customize financial products to meet your needs
  • verified_user KYC Documentation Support
    Comprehensive customer verification system
  • rule Business Rule Sets
    Configurable business logic and workflows
  • payments Payment Transactions
    Secure and efficient payment processing
  • account_balance Portfolio Management
    Complete loan and investment tracking

  • phone_iphone Mobile Access

  • api Open API

historyDeprecated Sub-Project Notice

The Fineract® CN project (microservice architecture version) was deprecated in May 2023 and archived in late 2023. While this side-project served an important role in describing a microservice approach, it was never officially released.

Verifying Downloads: We strongly recommend verifying the integrity of the downloaded files using:

  • ASC files - PGP signatures that can be verified using our KEYS file
  • SHA512 files - Checksums to verify the downloaded file hasn't been corrupted

For instructions on signature verification, please see the Apache Release Download Guide.

If you are looking for an old release that is not present here or on the mirror, please check the Apache archives.
